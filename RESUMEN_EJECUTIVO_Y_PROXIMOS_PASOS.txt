📞 SOPORTE - SI ALGO SALE MAL
═══════════════════════════════════════════════════════════════════════════════

Si un proyecto no despliega en Render:
  → Verifica el archivo Procfile
  → Revisa los logs en Render Dashboard
  → Asegúrate de que requirements.txt (Python) o pom.xml (Java) existen
  → Verifica que el Build Command es correcto

Si GitHub Pages no funciona:
  → Espera 2-3 minutos después de habilitar
  → Verifica que index.html existe en la raíz
  → Comprueba que la rama está en "main" en Settings > Pages

Si los links del portfolio no funcionan:
  → Verifica que las URLs de Render en index.html son correctas
  → Haz un push con los cambios: git add . && git commit -m "Fix URLs" && git push
