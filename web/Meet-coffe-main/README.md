# ☕ Meet & Coffee

Landing page del proyecto **Meet & Coffee** — una comunidad tech que se reúne
alrededor de un buen café para compartir charlas, eventos y simposios.

> Proyecto realizado como parte del bootcamp de **Desafío Latam**.

## ✨ Features

- 🎨 Diseño moderno con gradientes, glassmorphism y tipografía editorial
- 🌊 Animaciones al scroll (AOS) + contadores animados
- 🖱️ Cursor personalizado (solo desktop)
- 🌗 Navbar con cambio de fondo y progreso de scroll
- ⚡ Preloader temático (taza de café)
- 📱 100% responsive (mobile-first)
- ♿ Respeta `prefers-reduced-motion`

## 🛠️ Stack

- HTML5 semántico
- CSS3 (custom properties, grid, flexbox, animaciones)
- JavaScript vanilla (ES6+)
- [Bootstrap 5](https://getbootstrap.com/)
- [Font Awesome 6](https://fontawesome.com/)
- [AOS](https://michalsnik.github.io/aos/)
- Google Fonts: Inter + Playfair Display
