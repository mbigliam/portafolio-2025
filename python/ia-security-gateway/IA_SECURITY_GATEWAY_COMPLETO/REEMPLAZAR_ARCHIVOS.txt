→ Abre Consola (F12) y verifica errores
→ Revisa que API_BASE = 'http://localhost:8000/api' sea correcto
→ Verifica que el backend está en puerto 8000

Si la interfaz se ve vacía:
→ F5 (refresh) varias veces
→ Ctrl+Shift+Supr (limpiar caché)
→ Verifica que index.html se copió a public/
